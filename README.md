# 口袋新概念

小花个人使用的新概念英语第二册 H5 样本。按 20–30 分钟通勤场景设计，首版包含前三课：理解、听读、关键词背诵、隐藏英文串背、自评复习和随文生词。

## 在电脑预览

需要 Node.js 22 或更高版本。没有第三方 npm 依赖，无需安装依赖或构建。

```powershell
node scripts/prepare-audio.mjs "G:\课程文件\第2册美音"
npm start
```

浏览器打开 http://127.0.0.1:4173/ 。服务只监听本机，只提供 `app/` 内文件。不要直接双击 HTML，否则 ES Modules、数据库和离线功能可能不能正常工作。可用 `PORT` 环境变量修改端口，但不同地址/端口的学习进度独立。

当前电脑的前三课音频已复制好。原 MP3、PDF 不提交 Git，也没有上传到外部平台。

## 学习方式

1. 今天页开始或继续学习。课文页可自由切换前三课。
2. “理解”点开句意、讲解或词义；点击句子左侧播放键可点读。整理过的单词和词组有下划线。
3. “练句”支持一次播放、单句循环、跟读留白、整篇播放、0.75/1/1.25 倍速；可标记难句。
4. “提示背诵”逐步从完整英文切到关键词、隐藏英文。“串背”默认隐藏，提示使用单独记录。
5. 自评没背出/需要提示安排隔天复习；连续独立背出按 1、3、7、14 天递增。复习先进入标记的难句。这些是可调整的产品规则，不是自动评测结果。

学习进度在当前浏览器 IndexedDB 中保存，暂停/返回/刷新不会自动标记完成。恢复后由用户手动播放。词汇仅覆盖已整理词条，其他词明确提示未收录。

## 离线与备份

- 课文页点击“离线保存”，完成后显示“可离线”；文字和页面在 Service Worker 安装时缓存，音频单独保存。
- 音频缓存按完整文件保存，离线播放支持 Range 请求。移除音频不会删除学习进度。
- 设置里导出 JSON 进度备份；恢复前验证格式并展示条目数量，确认后整体替换。备份不含 MP3 和教材。
- 浏览器可能回收数据，清理浏览器或换设备前请导出。Safari 与主屏幕入口不假定共享进度。
- 代码更新后需要修改 `app/sw.js` 的 shell 缓存版本，以便更新离线资源。
